# Mercado Amigo PDV

chat, me ajuda a criar um pdv para um sistema de mercadinho, preciso de um sistema com frente de caixa e um sistema integrado, sistema para cadastro de produtos, cadastros de clientes, cadastros de fornecedores. 

Na forma que trabalhamos, recebemos mercadorias e efetuamos o lançamento do pedido, como nota de entrada (iremos precisar dessa diferenciação de qual natureza de lançamento está sendo realizada, se de compra, de troca, de saida e qual motivo (vencido, roubo, depreciação ou furo estoque).

Preciso também que no PDV tenha opções de lançamentos de vendas normais, também para clientes no conhecido "fiado", que será adicionado a venda a cada cliente previamente definido e assim será adicionado ao final do venda.

Preciso que no PDV tenha predefinição para impressão de cupom não fiscal da compra com todas as informações, preciso que você seja bastante interativa na confecção do sistema, alem de fazer observancia aos já existentes, faça incremente que podem beneficiar e ser uteis no meu sistema.
